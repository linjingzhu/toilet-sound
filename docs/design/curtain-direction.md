# 커튼 방향: 디자인 전환과 이름 검토

2026-10-12 기준 개발 기록. **커튼모드 / CURTAIN MODE는 화면에 적용한 가칭이며 최종 제품명은 미확정**이다.

## 디자인 전환

초기 개발에는 사용자가 고른 [Pure Ease 시안](assets/additional-01-pure-ease.png)의 따뜻한 아이보리·물결·청록 원형 버튼을 기준으로 삼았다. 이후 사용자가 새로 제시한 [커튼 스타일 참고 이미지](assets/curtain-style-reference.jpg)의 색감과 형태를 우선해 화면 스타일을 전환했다. 기존의 **여러 소리 선택 → 각 트랙 음량 조절 → 함께 재생**, 피아노 곡 변경, 전체 음량 조절이라는 믹서 구조와 기능은 이어받는다. 참고 이미지는 시각적 방향 자료이며, 앱의 화면 구성과 문구를 그대로 복제하는 기준은 아니다.

| 요소 | 현재 적용 방향 | 구현 기준 |
| --- | --- | --- |
| 메인 화면 | 밝은 펄그레이 `#EEF0F5`, 블루그레이 글자 | 제목과 재생 다이얼이 먼저 보이는 단정한 화면 |
| 소리 선택·피아노 시트 | 짙은 블루그레이 `#526783`, 밝은 글자 | 밝은 메인 화면과 명확히 구분되는 믹서 작업 면 |
| 활성 음량 | 라벤더 `#897DCC` | 슬라이더 채움과 재생·선택 상태에 제한적으로 사용 |
| 선택 완료 | 민트 `#81DBE5` | 어두운 시트의 주요 완료 동작에 사용 |
| 재생 조작 | 펄그레이 세라믹 원형 다이얼, 미세 눈금, 낮은 입체감 | 아이콘·한글 라벨은 이미지에 굽지 않고 실제 버튼의 live UI로 표시 |

밝은 면의 본문은 짙은 글자로, 어두운 면의 본문은 밝은 글자로 읽기 쉽게 유지한다. 라벤더와 민트는 주로 상태·조작의 강조색으로 사용하고, 뉴모피즘 그림자만으로 조작 가능 여부를 전달하지 않는다. 현재 화면의 실제 값과 라벨은 [`app/src/prototype.css`](../../app/src/prototype.css), [`app/src/veil/VeilApp.tsx`](../../app/src/veil/VeilApp.tsx)에 따른다.

현재 화면에는 영문 워드마크 `CURTAIN MODE`(접근성 라벨 `커튼모드`), 제목 `나만의 소리 커튼`, 전체 음량 라벨 `커튼 음량`이 표시된다. 다이얼의 화면 문구는 `커튼 켜기`이고, 재생 버튼의 실제 접근성 이름은 `믹스 재생`이다. 화면 하단의 `광고 예시`는 샘플 광고 영역이며 실제 광고 SDK 연동이나 집행을 뜻하지 않는다.

## 이름 후보

| 후보 | 판단 | 유의점 |
| --- | --- | --- |
| **커튼모드** | 현재의 절제된 도구형 디자인과 잘 맞는다. “커튼모드 켜기”처럼 동작 문구로 쓰기 쉽다. 화면 가칭으로 유지한다. | 일반 기능명처럼 들릴 수 있다. 삼성전자 세리프 TV의 UI 이름에도 `커튼모드`가 실제로 쓰였다.[^samsung] |
| **쉿커튼** | 짧고 소리를 가린다는 뜻이 비교적 선명하다. 최종 이름에서 개성을 더하고 싶을 때 비교할 후보. | 친근한 대신 다소 장난스럽거나 유아적인 인상을 줄 수 있다. |
| **살랑커튼** | 부드러운 소리와 편안한 분위기를 잘 담는다. | 이름만으로 믹서·소리 가리기 기능을 알아채기 어렵다. |

**현재 판단:** 디자인과 조작 문구에는 `커튼모드`가 가장 자연스럽다. 다만 사용 가능한 최종 브랜드라는 뜻은 아니다. `커튼온`은 이미 공연 정보·커뮤니티 앱 이름으로 App Store에 사용 중이다.[^curtainon] `Focus & Relax Sound Curtain`은 백색소음·자연 소리를 섞는 앱으로 Google Play와 App Store에 올라와 있어, `소리커튼`처럼 단순한 직역형 이름의 차별성도 별도로 따져야 한다.[^soundplay][^soundios] 이 관찰은 상표권, 등록 가능성, 스토어 심사, 검색 성과를 보장하거나 단정하지 않는다.
