# VEIL MVP 개발 안내

작성일: 2026-10-12 · 상태: 첫 Flutter MVP

## 구현 범위

- 시안 1 `Pure Ease`의 큰 재생 버튼과 가로 음량 조절을 기반으로 한 단일 믹서 화면
- 흐르는 물, 새소리, 화이트 노이즈, 핑크 노이즈와 피아노 2종
- 여러 환경음과 피아노 1곡의 동시 선택, 트랙별 음량, `VEIL 음량`
- 피아노 교체 시 환경음 유지, 마지막 선택과 음량 저장
- 오류 스낵바, 접근성 레이블, 음원·오디오 정책 안내
- 조작부와 분리한 광고 자리 표시자. 광고 SDK는 미연결

## 오디오 구조

각 음원은 독립 `AudioPlayer`를 사용합니다. 트랙 변경으로 믹서 전체를 다시 만들지 않으며, `VEIL 음량`은 각 트랙 게인에 곱해지는 앱 내부 값입니다.

- iOS 후보: `AVAudioSessionCategory.playback`과 `mixWithOthers`, 백그라운드 오디오 모드
- Android 후보: `handleAudioSessionActivation: false`로 플레이어의 자동 오디오 포커스 요청 방지

이는 구현 후보가 코드에 반영되었다는 의미입니다. 실제 유튜브 동시 재생, 덕킹 여부, 잠금 화면 유지와 출력 전환은 [실기기 시나리오](audio-coexistence.md#출시-통과-검증-시나리오)로 확인해야 합니다.

## 개발 명령

```bash
flutter pub get
dart run tool/generate_audio_assets.dart
flutter analyze
flutter test
```

`tool/generate_audio_assets.dart`는 재현 가능한 WAV 샘플을 생성합니다. 이 음원은 기능 검증용이며 출시용 음원 선정과 라이선스 검토를 대신하지 않습니다.

## UX 계약

| 항목 | 동작 |
| --- | --- |
| 진입점 | 앱 실행 후 마지막 믹스가 정지 상태로 표시됨 |
| 기본 행동 | 중앙 `재생` 버튼으로 선택된 믹스를 시작·일시정지 |
| 가시 결과 | 버튼 레이블과 아이콘이 재생 상태에 맞게 변경됨 |
| 주요 상태 | 정지, 재생, 시작 처리 중, 재생 오류 |
| 소리 추가 | 하단 선택창에서 환경음을 켜거나 끔 |
| 복구 | 재생 오류를 스낵바로 알리고 다시 재생 가능 |
| 도움말 | 우측 상단 안내에서 VEIL 음량 범위와 샘플 음원을 설명 |
