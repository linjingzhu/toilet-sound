# 커튼모드 제품 요구사항

작성일: 2026-10-12 · 상태: 개발 착수용 초안 · 제품명: 커튼모드(최신 가칭, 최종명 미확정)

## 목적과 현재 상태

물소리, 자연음, 백색소음과 음악을 섞어 화장실에서 느끼는 소리에 대한 민망함을 줄이는 모바일 매너 앱을 만든다. Google Play와 Apple App Store 모두에서 서비스한다.

사용자는 2026-10-12 **추가 시안 1번 · Pure Ease**로 개발 시작을 지시했다. 공통 화면·웹 믹서와 Android/iOS 네이티브 오디오 기반을 구현하는 첫 개발 버전이며, 실기기 수용 검증은 아직 없다. 디자인 선택 기록은 [사용자 결정 항목](OWNER_ACTIONS.md)의 `DESIGN-001`, 구현·검증 상태는 [개발 보고](../.ai/reports/2026-10-12-pure-ease-development.md)에서 확인한다. 이 문서는 출시 완료를 의미하지 않는다.

## 사용자가 확정한 핵심 요구

| ID | 요구사항 | 수용 기준 |
| --- | --- | --- |
| R-01 | 다른 앱과 동시 재생 | 유튜브 등 다른 앱과 소리를 함께 재생한다. 커튼모드가 상대 앱을 정지시키거나 상대 앱의 음량을 자동으로 낮추지 않는다. **최우선 개발·출시 검증 항목**이다. |
| R-02 | 소리 선택과 혼합 | 물소리, 새소리, 백색소음 등을 선택하고 여러 소리를 동시에 섞을 수 있다. |
| R-03 | 음악 혼합 | 피아노 연주 같은 음악을 환경음과 함께 들을 수 있다. 음악의 변경·정지는 이미 재생 중인 환경음을 끊지 않는다. |
| R-04 | 개별 음량과 앱 음량 | 소리별 음량과 커튼모드 전체 믹스의 음량을 조절한다. 앱 전체 슬라이더의 명칭은 `커튼 음량`으로 하며, 상대 앱이나 시스템의 미디어 음량을 바꾸지 않는다. |
| R-05 | 광고 수익 | 무료 이용과 광고 수익을 기본 모델로 한다. 광고의 표시·갱신 때문에 커튼모드나 상대 앱의 오디오가 중단되거나 작아지지 않아야 한다. |
| R-06 | Android와 iOS | 두 플랫폼 모두에서 핵심 기능을 제공하고, 동시 재생 지원 범위를 플랫폼별 실기기 결과로 확인한다. |

대표 흐름은 **커튼모드에서 믹스 재생 → 유튜브로 이동 → 영상 소리와 커튼모드 소리를 함께 듣기**다. 다른 앱으로 이동한 뒤에도 커튼모드 재생을 유지할 수 있어야 한다. 상대 앱 자체의 백그라운드 재생 제한까지 커튼모드가 해제할 수 있다는 의미는 아니다. 상세 조건은 [다른 앱과의 동시 재생 설계](audio-coexistence.md)를 따른다.

| 기술 구성 | React·TypeScript + Capacitor 8, Web Audio 및 Java/Swift 로컬 플러그인. 광고 SDK 선정·연동은 후속 단계 |

## 디자인과 기능의 경계

- 주 화면에는 재생·정지, 선택한 소리, 개별 음량, `커튼 음량`, 소리 추가, 음악 변경, 출력 장치 상태를 우선 배치한다.
- 광고와 재생·음량 조작부를 분리하고, 급하게 켜야 하는 사용 흐름을 방해하지 않는다.
- 마이크를 이용한 주변 소리 수집이나 녹음 기능은 두지 않는다. 소음 분석을 위한 녹음 권한도 기본 요구에 포함하지 않는다.
- 소리를 겹쳐 주변 소리가 덜 두드러지게 하는 마스킹 제품으로 설계한다. 실제 ANC, 소음 제거율, 완전한 차음 효과를 보장하는 표현은 사용하지 않는다.
- 광고 SDK의 데이터 처리·동의·스토어 고지 범위는 SDK 선정 후 확인한다. 녹음하지 않는다는 설계만으로 개인정보 처리가 전혀 없다고 표시하지 않는다.

## 첫 개발 버전의 수용 상태

R-02·R-03·R-04의 웹 믹서 구현과 설정 복원은 자동 테스트·브라우저 조작으로 확인한다. 이는 실제 기기의 소리 품질이나 외부 앱 재생을 검증한 결과가 아니다. R-01·R-06의 네이티브 실기기 검증과 R-05의 실제 광고 SDK 수용 검증은 미실시다.

| 번호 | 다음 할 사항 | 완료 기준 |
| --- | --- | --- |
| 1 | 두 플랫폼 빌드·실기기 설치 | Android·iOS 네이티브 실행 결과 확보 |
| 2 | 동시 재생·백그라운드·출력 경로 검증 | R-01·R-06 지원 조건 기록 |
| 3 | 출시용 음원 품질 결정 | 청취·반복·음량·사용 권한 확인 |
| 4 | 광고 SDK 결합 후 재검증 | R-05 및 동시 재생 재확인 |

출시 통과 조건과 기록 항목은 [오디오 검증 시나리오](audio-coexistence.md#출시-통과-검증-시나리오)에 정리한다.

## 최신 디자인 반영

2026-10-12 사용자의 추가 참고 이미지를 기준으로 펄그레이 홈, 블루그레이 선택 시트, 라벤더·민트 포인트와 입체적인 다이얼을 적용했다. 최초 Pure Ease 선택은 개발 착수 기록으로 보존하며 최신 스타일은 [커튼 방향 문서](design/curtain-direction.md)를 따른다. 제품명은 제안 단계이고 내부 패키지·플러그인·식별자에는 기존 VEIL 이름을 사용한다.
