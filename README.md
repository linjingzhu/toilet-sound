# toilet-sound

앱 가칭: **VEIL / 베일**

화장실에서 느끼는 소리의 민망함을 줄이기 위한 모바일 사운드 믹서 앱입니다. 물소리, 새소리, 백색소음과 피아노를 원하는 음량으로 섞고, 유튜브 등 다른 앱을 사용하면서 함께 들을 수 있는 제품을 기획합니다.

## 현재 상태

**기획 및 개발 준비 단계입니다.** 이 저장소에는 초기 제품 요구사항과 개발 지침이 들어 있습니다. 실행 가능한 앱, 광고 연동, 음원 파일, 실기기 검증 결과는 아직 없습니다.

- 서비스 대상: Android / Google Play, iOS / App Store
- 수익 모델: 광고형
- 가칭: VEIL / 베일 — 최종 명칭 미확정
- 디자인: 메인 믹서 시안 3종 작성, 최종 시안 미선택
- 기술 검토 방향: Flutter 및 AdMob. 실제 오디오 검증을 거쳐 구현 구성을 결정합니다.

## 핵심 요구사항

- 물소리·새소리·백색소음 등 여러 소리를 선택하고 혼합합니다.
- 피아노 같은 음악을 환경음과 함께 재생합니다.
- 소리별 음량과 **VEIL 음량**을 독립적으로 조절합니다. VEIL 음량은 이 앱의 출력만 조절합니다.
- **유튜브 등 다른 앱과 동시에 재생하며, VEIL이 상대 앱을 정지시키거나 음량을 자동으로 낮추지 않게 합니다.**
- 피아노 추가·교체·정지가 환경음이나 다른 앱의 재생을 중단시키지 않게 합니다.
- 광고 표시·갱신이 오디오 재생을 방해하지 않게 합니다.

소리를 덧씌워 들리는 정도를 완화하는 사운드 마스킹 제품입니다. 주변 소리를 제거하는 능동 소음 제거(ANC)나 완전한 차음을 보장하지 않습니다.

## 개발 규칙

공통 개발 규칙의 기준은 [linjingzhu/ai-dev-rule](https://github.com/linjingzhu/ai-dev-rule)입니다.

- 기준 브랜치: `stable`
- 규칙 세트: `4.1.0`
- 고정 커밋: `7e9013d4594a94486152d8a74a5b9252bfcd4297`
- 연결 방식: **외부 참조**. `ai-dev-rule`은 비공개 저장소이므로 접근 권한이 있는 개발 환경에서 원문을 읽습니다.

Codex는 [AGENTS.md](AGENTS.md), Claude Code는 [CLAUDE.md](CLAUDE.md)를 통해 해당 도구의 원본 진입 지침을 읽습니다. 공통 규칙의 상대 경로는 규칙 저장소에서, 프로젝트별 문서는 이 저장소에서 해석합니다. 현재 연결은 `adopt.py`로 정책·도구·에이전트를 복제한 구성이 아니며 `.ai/set.lock`을 생성하지 않습니다.

실행 가능한 앱이나 CI 워크플로는 아직 없습니다. 규칙 세트가 제공하는 자동 개발 절차를 이 저장소 초기화 작업에서 시작하지 않습니다.

## 개발 시작 순서

1. Android와 iPhone에서 오디오 실험을 만들어 유튜브 동시 재생을 먼저 검증합니다.
2. 실행 순서, 앱 전환, 음원 변경, 앱 음량 조절, 광고 SDK 영향의 결과를 기록합니다.
3. 검증 결과에 따라 오디오 라이브러리와 플랫폼별 구현을 결정합니다.
4. 선택된 디자인을 기준으로 믹서와 음원 선택 화면을 구현합니다.
5. 사용 권리를 확인한 음원과 광고를 연결하고, 두 플랫폼의 출시 검증을 진행합니다.

현재 앱 실행·빌드·테스트 명령은 정의되어 있지 않습니다. 앱 프로젝트를 추가할 때 실제로 검증한 명령을 이 문서에 기록합니다.
