# 커튼모드 디자인 QA

- 검증일: 2026-10-12, Asia/Seoul
- final result: passed
- 범위: 사용자가 제공한 참고 이미지의 색감·재질을 실제 소리 믹서에 적용한 웹 렌더링. 네이티브 컴파일·실기기 오디오 판정은 포함하지 않는다.

## Findings

현재 확인 범위에서 실행 가능한 P0·P1·P2 디자인 문제는 남아 있지 않다. 예비 검토에서 발견한 피아노 변경 버튼의 하단 잘림을 수정했고, 최종 홈 화면은 1:1 크기로 다시 캡처했다. 제품명은 가칭이며 이름 확정은 별도 사용자 결정이다.

## Full-view 및 세부 검토

원본의 펄그레이·블루그레이 대비, 라벤더·민트 강조, 원형 다이얼, 낮은 그림자와 들어간 슬라이더 레일을 홈과 선택 시트에 옮겼다. 상단 재생, 가운데 믹스, 하단 고정 전체 음량과 광고의 기능 순서를 유지했다.

최종 393 × 852px 원본 캡처에서 제목, 곡 이름, 음량 수치, 선택 표시와 광고 구분이 모두 읽힌다. 중요한 부위인 다이얼 경계·슬라이더 손잡이·선택 카드·하단 버튼도 이 크기에서 판단할 수 있어 별도의 확대 크롭은 만들지 않았다. 원본 스타일 보드는 원래 685 × 1200px 크기로 함께 열었다.

| 필수 fidelity surface | 비교 결과·허용한 차이 |
| --- | --- |
| Fonts / typography | 원본의 가늘고 절제된 영문 타이포그래피를 참고했다. 한글 UI에는 로컬 Noto Sans KR와 400·500 중심의 위계를 사용한다. 원본의 정확한 글꼴은 미상이며 같은 글꼴이라고 주장하지 않는다. 제목·트랙·보조 설명을 구분하고 수치·한글 줄바꿈·말줄임을 확인했다. 실제 기기 상태 표시줄은 보호 런타임의 플랫폼 글꼴을 유지한다. |
| Spacing / layout rhythm | 홈 좌우 여백, 원형 재생부, 일정한 트랙 행 간격과 고정 하단 조작부를 확인했다. 원본 EQ의 세로 슬라이더는 여러 소리의 이름·음량을 바로 비교할 수 있는 가로 레일로 적용했다. 기본 3개 믹스에서 곡 변경 버튼이 전체 음량 위에 온전히 표시된다. |
| Colors / tokens | 홈 `#eef0f5`, 본문 `#334156`, 보조 `#606c7e`, 선택 시트 `#526783`, 라벤더 `#897dcc`, 민트 `#81dbe5`를 사용한다. 원본에서 추정한 색상 방향이며 정확한 원본 토큰 추출값은 아니다. 선택 상태는 색상과 체크 아이콘으로 함께 표현한다. |
| Image quality / assets | 참고 이미지 방향으로 생성한 1254 × 1254 RGBA 세라믹 다이얼을 180px 슬롯에 표시한다. 투명 여백 안의 원형 표면·미세 눈금이 자연스럽고 눈에 띄는 사각 배경·깨진 이미지·불필요한 번짐이 없다. 표준 조작 아이콘은 Phosphor를 사용한다. 사용자 참고 이미지 자체를 작동 화면으로 덮어씌우지 않았다. |
| Copy / content | `CURTAIN MODE`, `나만의 소리 커튼`, `다른 앱과 함께 편안하게`, `커튼 켜기`, `커튼 음량`의 문구를 확인했다. 홈에 실제 엔진 출력 이름을 표시한다. 광고는 `광고 예시`로 명확히 구분한다. 메트로놈 숫자나 원본 제품명을 복사하지 않았다. |

브라우저 자동화의 일부 locator 클릭은 보호된 phone screen 자체를 스크롤하며 숨겨진 키보드 자산을 노출했다. 같은 버튼을 실제 AX 클릭으로 조작하면 scrollTop 0과 정상 레이아웃이 유지됐다. 이를 앱에서 키보드가 열린 문제로 오인해 보호 런타임을 수정하지 않았다. 탭의 키보드 포커스 이동에는 `preventScroll`을 사용한다.

## Open Questions / 테스트 경계

- `커튼모드`는 디자인 가칭이다. 최종 이름 및 사용 가능성은 아직 확정하지 않았다.
- Android·iOS 실제 컴파일, YouTube 동시 재생·잠금·중단·출력 경로는 별도 기기 검증 항목이다. 이 디자인 QA로 통과 처리하지 않는다.
- 실제 기기 스크린리더·확대 글꼴 200%·장시간 오디오·광고 SDK 동작은 미검증이다.
- 네이티브 앱 아이콘은 아직 기본 자산이다. 최종 브랜딩과 스토어 이미지 제작은 후속 작업이다.
